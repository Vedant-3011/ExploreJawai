# Explore Jawai — Website Prototype

A responsive five-page website prototype for https://explorejawai.com/.

## Pages
- `index.html` — Home
- `explore-jawai.html` — Explore Jawai
- `plan-your-trip.html` — Plan Your Trip
- `blog.html` — Blog index linked to currently published Explore Jawai articles
- `contact.html` — Contact page with a front-end enquiry form prototype

## Design direction
Editorial, premium nature-travel identity using forest green, warm ivory, sandstone and terracotta. The emblem is an original SVG concept created for this prototype. The hero photograph is AI-generated specifically for this prototype.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Important before production
1. This is a static front-end prototype, not yet installed on the live WordPress website.
2. The contact form is not connected to an email inbox or CRM. Connect it to WordPress Forms, Jetpack Forms, Fluent Forms, Contact Form 7 or another approved form handler.
3. Verify current transport, safari, access, accommodation and visitor details before publishing.
4. Replace or supplement generated imagery with licensed, authentic Jawai photographs where available.
5. Check all page copy, image accuracy, SEO metadata and links before deployment.
6. The Blog page currently links to the 10 posts visible on ExploreJawai.com during the website review on 20 November 2026. Update the list as new posts are published.
